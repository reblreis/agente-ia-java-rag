# 🤖 Agente de IA com Java e Spring AI

Projeto desenvolvido durante o curso de Desenvolvimento
de Agentes de IA em Java.

## 🚀 Tecnologias

- Java 21
- Spring Boot
- Spring AI
- RAG (Retrieval-Augmented Generation)
- PostgreSQL
- pgvector
- MongoDB
- Docker
- OpenAI API

## 🧠 Funcionalidades

- Integração com modelo de IA
- Busca semântica com RAG
- Armazenamento de embeddings
- Memória conversacional
- Respostas estruturadas
- Tool Calling / Function Calling

## 🏗️ Arquitetura

Aplicação desenvolvida com Spring Boot e Spring AI,
utilizando banco vetorial para recuperação de conhecimento
e MongoDB para persistência do histórico.
